Reference Disk Source-Driven Growth: Continuation

This page collects the continuation-side evidence for the source-driven reboot. The continuation branch is retained as a mapping tool: it shows that a smooth, high-source branch exists on the simple disk, but it is not the production biology lane and it is not the surface from which the direct-start decision is made.

The successful growth reference remains the canonical disk kinematic-growth campaign. This continuation surface is only the source-driven branch map that sits beside that reference.

What It Proves

Supported continuation runs cleanly from s=2 through s=75, with mechanically healthy green histories and min_J staying near 1.0 on the tracked branch.

What It Does Not Prove

It does not replace direct-start biology. The reboot evidence shows that continuation and direct start select different branches, so this study should be read as context and branch mapping only.

Decision Impact

Continuation remains useful for diagnosing branch accessibility, but the forward modeling decision was made from the direct-start studies: pf-only with conservative early-time dt.
