Reference Disk Source-Region Localization

Public source-region localization tier for the `pf-only` `s=30` direct-start screen.

Interpretation Note

  • All runs use the simple disk, direct start, conservative global `dt = 5e-4`, and `component_steering = false`.
  • The purpose is to determine whether `all`, `tissue`, or `lumen` is the least pathological `pf-only` source-region choice before any future biology-facing calibration work.
  • On the current packaged evidence, `all` narrowly wins in both hydraulic modes, `tissue` is a close second, and `lumen` is last in both modes.
