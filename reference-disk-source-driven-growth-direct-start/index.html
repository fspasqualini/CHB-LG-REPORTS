Reference Disk Source-Driven Growth: Direct Start

This is the current decision-facing entrypoint for the source-driven reboot. It consolidates the screened direct-start studies rather than exposing each detailed ticket study at the portal root.

Current carried-forward lane: fixed-mesh simple-disk direct start with pf-only and conservative early-time dt. In the current implementation this means a pressure-scaled source acts in the pf equation while the theta source channel is disabled. This is a pragmatic least-pathological fixed-mesh screen, not a validated tissue-birth law or proof that the source law is biologically complete.
