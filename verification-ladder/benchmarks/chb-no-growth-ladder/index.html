What This Benchmark Verifies

This ladder checks retained coupled-state accuracy against a same-equations overkill reference on the canonical no-growth disk.

Benchmark Narrative

Narrative

Physical Problem

Canonical four-lumen disk with no growth, no hydration, and no osmotic forcing is run at three numerical fidelities so the page can isolate discretization-driven drift during lumen coarsening on a fixed benchmark geometry.

Narrative

Target Definition

The target is the overkill reference lane (finer time-step and tighter tolerances) run on the same equations and geometry. The expected trend is that the medium lane should remain closer to the reference than the coarse lane while preserving the same topological event ordering.

Narrative

Why These Observables

The setup schematic explains the toy problem, the topology-history plot is a raw example of how lumen coarsening evolves over time, the field triptych shows a real final-state pf snapshot from medium versus reference, scalar and field error bars summarize extracted observables, and merge-time errors capture the topology-sensitive part of the run.

Narrative

How To Read The Error

Retained accuracy is primarily seen by refinement trend: medium should improve over coarse in scalar and field errors, and its field snapshot should visually resemble the reference more closely. Large state errors indicate coupled-state drift, while isolated merge-time spikes can expose topology mismatches even when bulk metrics look acceptable.

Narrative

Reference Qualification

All lanes use the same public init/run workflow; comparisons are on common accepted physical times with t=0 excluded, and merger event times are tracked separately from state-space error metrics because this is the most topology-sensitive part of the benchmark.

Narrative

Limitations

Single canonical disk geometry, no-growth lane family only, and this page currently renders extracted pf field slices rather than the full media lane used by the public simulation-study pages.
