What This Benchmark Verifies

This exact-contract benchmark confirms algebraic and constitutive identities before coupled dynamics are exercised.

Benchmark Narrative

Narrative

Physical Problem

This page checks that the public startup path is consistent across the supported lane variants that later verification pages compare against one another.

Narrative

Target Definition

The target is exact cross-lane startup compatibility as encoded in `tests/vv/test_startup_compatibility.py`.

Narrative

Why These Observables

The schematic shows the lane-parity intent, the raw pytest status plot exposes each compatibility case, and the grouped view summarizes which startup lanes are covered.

Narrative

How To Read The Error

If startup lanes disagree here, any later expected-versus-achieved or reference-ladder comparison is contaminated by initialization drift rather than solver behavior.

Narrative

Reference Qualification

The benchmark is defined directly by the repo's startup compatibility pytest surface.

Narrative

Limitations

This page isolates startup equivalence only. It does not compare time histories.
