What This Benchmark Verifies

Benchmark Narrative

Narrative

Physical Problem

Tier-zero local identities exercise the symbolic and constitutive contracts that later VV pages assume are exact before any PDE solve or mesh-discretization question begins.

Narrative

Target Definition

The target is exact contract satisfaction at machine precision for the identity families covered in `tests/vv/test_local_identities.py`.

Narrative

Why These Observables

The abstract contract schematic shows what later VV pages depend on, the pytest status plots expose the raw exact-contract outcomes, and the grouped category status summarizes which identity families are being exercised.

Narrative

How To Read The Error

Any failure is a contract break or harness issue, not discretization noise. These pages should be read as exact prerequisites for every later verification family.

Narrative

Reference Qualification

The benchmark is backed directly by the repo's local-identity pytest module, which is the authoritative exact-contract surface for these constitutive checks.

Narrative

Limitations

This page does not test time integration, mesh refinement, or coupled dynamics. It only certifies exact upstream identities.
