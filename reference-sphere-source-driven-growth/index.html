Macro Study

Reference Sphere Source-Driven Growth

This macro study promotes the long-horizon sphere transfer of the carried-forward direct-start pf-only lane. It packages the completed s=30 closed and leaky runs, the completed s=75 closed run, and three comparison bundles for geometry- transfer review.

The promoted sphere surface excludes the short-horizon s=75 probe. All visual artifacts use a shared fixed 3D framing box, padded from the largest deformed sphere configuration across the included long-horizon sphere runs, and each run exposes both standard and warped field views.

Current reading: on the sphere, both long-horizon s=30 runs stayed controller-clean, and the long-horizon s=75 closed run did not reproduce the earlier pathological disk s=75 direct-start collapse. The disk pathology comparison is included to make that transfer question explicit rather than implicit.
